# Hospital Centenario — Portal V14

V14 reemplaza las fotografías del carrusel por nuevas imágenes públicas del Hospital Centenario/Bicentenario y elimina el desenfoque artificial.

## Fotografías
Las imágenes se cargan desde URLs públicas de medios que publicaron fotografías del hospital. Se eligieron encuadres del edificio nuevo, interior y edificio histórico para evitar las imágenes pixeladas de las versiones anteriores.

## Importante
Esta versión usa imágenes remotas para conservar la resolución publicada por sus fuentes. Si el hospital dispone de fotografías originales en alta resolución, lo ideal para una versión definitiva es incorporarlas al proyecto con autorización y derechos de uso.

El resto del portal mantiene la estructura y funcionalidades de V12.
